# Torque 12 Garage — demo interna Vértice Web

Projeto automotivo demonstrativo integrado ao portfólio Vértice.

## Estrutura ativa
- `index.html`
- `styles.css`
- `script.js`
- `branding.txt`

A versão atual não depende de vídeos locais nem de sequências antigas de frames. Os arquivos de mídia experimental que não eram referenciados pela página foram removidos na V7 para reduzir o peso do pacote e evitar publicar assets mortos.

Algumas imagens visuais do projeto são carregadas de provedores externos; valide a disponibilidade final após publicar em HTTPS.
