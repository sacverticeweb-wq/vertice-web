BRANDING — COBALTO BARBEARIA / ISSUE 001

NICHO
Barbearia urbana / estúdio de grooming.

SLOGAN
Precisão no corte. Presença no detalhe.

NOVA DIREÇÃO VISUAL
Editorial de rua + luxo bruto.
A marca abandona o visual “dark tech / glass / dashboard” e passa a funcionar como uma publicação independente: papel quente, tinta azul cobalto, preto de impressão, fotografia crua, serifas expressivas, grotescas pesadas, grid assimétrico, marcas editoriais, etiquetas e composição com imperfeição controlada.

PALETA
Cobalto: #1746FF
Ink Black: #101010
Newsprint: #F0EDE5
Warm Paper: #E6E1D7
Off White: #FAF9F5

TIPOGRAFIA
Display: Archivo Black
Editorial / contraste: Instrument Serif
Interface: Manrope
Dados / legenda: IBM Plex Mono

PRINCÍPIOS
1. Tipografia é a imagem.
2. Fotografia parece editorial, não banco de imagens corporativo.
3. Motion cria ritmo, não enfeite.
4. Imperfeição é intencional: rotação, fita, papel, textura, recortes.
5. Azul aparece como tinta e bloco gráfico — não como glow neon.
6. Nada de cards genéricos em bento grid.
7. Mobile mantém o impacto editorial, sem virar uma versão “compactada”.

TOM DE VOZ
Curto, urbano, seguro, sem frases de luxo genéricas.
Exemplos: “Corte é linguagem.” / “Sem padrão pronto.” / “Escolhe. Marca. Senta.”
