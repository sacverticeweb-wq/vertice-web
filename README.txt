VÉRTICE WEB — V7 SCROLL PRESENCE

Esta versão parte do upload vertice-web-site(5).zip.

Mudanças principais:
- Portfólio atualizado para 5 projetos internos navegáveis.
- Scroll Presence: linhas de seção, profundidade, movimento de luz e indicador editorial lateral.
- Navbar ganha profundidade/sombra mais forte e acabamento premium após o primeiro scroll.
- Reveals mais presentes, alternando direção de forma controlada.
- Movimento dos Live Viewers passa a reagir levemente ao scroll.
- Processo ganha progressão visual conforme cada etapa entra na viewport.
- Copy principal refinada para uma linguagem mais institucional/profissional.
- Arquivos duplicados e versões aninhadas removidos.
- Assets de mídia não utilizados da Torque 12 removidos para reduzir drasticamente o pacote.

Abra index.html para visualizar.
